# Prototype

The design reference is the "Shopinbos App Prototype" canvas:
https://claude.ai/artifact/9Fp8sRu3om4Vt6xCrrgP11

It has the boards Full app (mobile + web), Logistics app (partners + riders), Store templates
(Adire, Breeze, Noir, Plain, Pantry, Ilé, Plug, Stride) and Journeys. Each phase copies the
behaviour of its screens from there when the spec is silent (CLAUDE.md working rules).

Exported HTML can be dropped here for offline reference. Don't import from it.
