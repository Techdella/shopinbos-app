# Translations to review (dropship wording: not private label)

Shopinbos does dropshipping, not private or white label. The supplier sends its own product, in its own packaging, straight to the shop's customer; the shop sets its own price and owns the customer; the supplier never uses the parcel to sell to that customer directly. The delivery label still shows the shop's order so the customer knows which shop it came from.

Every string changed in this change, in all five languages. The Pidgin, Yorùbá, Hausa and Igbo text was drafted by Claude and still needs a native speaker: fix it in `shared/i18n/messages/<namespace>/<language>.ts` and keep every `{placeholder}` exactly (see `shared/i18n/README.md`). The same English is mirrored in `shared/feature-intros.ts` (supplier-products scene 3, supplier-agreements scene 2) and `shared/glossary.ts` (dropship-agreement example).
