# API keys and settings

Every environment variable the app reads, grouped by what it switches on. Add them in Vercel → Project → Settings →
Environment Variables (and `.env.local` for local work; `.env.local.example` has the same list with notes).
Section 1 is required: the app doesn't run properly without it. Everything else switches a feature on; without it
that feature hides itself or falls back.

## 1. Core (must have)

```
DATABASE_URL
DIRECT_URL
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY
NEXT_PUBLIC_APP_URL
NEXT_PUBLIC_ROOT_DOMAIN
CRON_SECRET
AUTH_COOKIE_SECRET
JWT_SECRET
```

Also: `NEXT_PUBLIC_STORAGE_BUCKET`, `PRIVATE_STORAGE_BUCKET`, `NEXT_PUBLIC_STORE_SUBDOMAINS`, `SHOPINBOS_ADMIN_INVITE_EMAILS`,
`NEXT_PUBLIC_SUPPORT_WHATSAPP`, `CSRF_TRUSTED_ORIGINS`, `APP_URL`, `PRISMA_POOL_LIMIT`.

`<PARTNER>_SECRET_KEY` / `<PARTNER>_WEBHOOK_SECRET`, `<PARTNER>_BASE_URL` (sandbox vs live), `<PARTNER>_ENV`.

`GOOGLE_STATIC_MAPS_BASE_URL`, `NIPOST_API_BASE_URL`, `NOMINATIM_BASE_URL`, `PAYSTACK_BASE_URL`, `PAYSTACK_API_BASE_URL`,
`META_GRAPH_BASE_URL`, `VERCEL_API_BASE_URL`, `TIKTOK_API_BASE_URL`, `GOOGLE_MERCHANT_API_BASE_URL`), `OPENAI_BASE_URL`,
`MOCK_SUPABASE_PORT`, `SMOKE_BASE_URL`, `SUPABASE_ACCESS_TOKEN`. Vercel sets `VERCEL`, `VERCEL_ENV`, `NODE_ENV` itself.
